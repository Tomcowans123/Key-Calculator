# Key-Calculator

<img width="1002" height="532" alt="KeyCalcGif" src="https://github.com/user-attachments/assets/e69c35ec-5c80-4ea5-9067-afcf4b216c98" />


Key Calculator is a Project designed to help musicians and songwriters write songs inside of musical keys by displaying the notes, chords and common progressions inside that musical key.

The application uses an algorythimc approach to calculte the notes in the key as oppose to hard coding the correct notes in each of the individual key to allow for easy scaling and modularity.
